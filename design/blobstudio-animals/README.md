# Blob Studio 动物轮廓源文件

这些 SVG 使用 Blob Studio 的 228×228 面部坐标系制作，可直接拖入 https://www.blobstudio.xyz/ 继续调整面部位置、表情、渐变和动画。

- cat.svg — 猫咪
- rabbit.svg — 兔子
- fox.svg — 狐狸
- bear.svg — 小熊
- panda.svg — 熊猫基础轮廓（应用内另叠加熊猫眼斑）
- owl.svg — 猫头鹰
- dog.svg — 小狗
- dragon.svg — 小龙

应用内成品定义位于 `src/components/animalMascotShapes.ts`，额外包含耳朵内层、胡须、眼斑、翅膀等品牌化细节。
